# Чат-бот Опросник для СДУТ (Система долговременного ухода Тольятти)

Простой интерактивный опросник на базе Yandex MAX API для сбора информации от пользователей паблика СДУТ.

## Функциональность

✅ **Интерактивный опросник** - пошаговый сбор информации  
✅ **Валидация данных** - проверка корректности email и телефона  
✅ **Сохранение результатов** - все ответы сохраняются в JSON  
✅ **Экспорт данных** - возможность скачать все собранные ответы  
✅ **Интеграция с MAX API** - работает через webhook'и Yandex MAX  

## Структура проекта

```
├── chatbot_survey.py          # Основной класс SurveyBot
├── max_bot_integration.py     # Flask приложение для MAX API интеграции
├── requirements.txt            # Python зависимости
├── .env.example               # Пример конфигурации
└── survey_responses.json      # Сохраненные ответы (создается автоматически)
```

## Вопросы опросника

Бот задает следующие вопросы:

1. **Имя** (обязательно) - "Как вас зовут?"
2. **Телефон** (обязательно) - "Укажите ваш номер телефона:"
3. **Email** (обязательно) - "Укажите ваш email:"
4. **Организация** (опционально) - "Ваша организация / место работы:"
5. **Тип запроса** (обязательно) - "Тип вашего запроса:" (выбор из вариантов)
   - Консультация
   - Обучение
   - Партнерство
   - Другое
6. **Сообщение** (обязательно) - "Опишите вашу проблему или вопрос:"

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
# Отредактируйте .env с вашими параметрами MAX API
```

### 3. Запуск приложения

```bash
python max_bot_integration.py
```

Приложение запустится на `http://0.0.0.0:5000`

## Интеграция с Yandex MAX

### Настройка webhook'а

1. Перейдите в консоль разработчика MAX
2. Добавьте URL вашего сервера как webhook:
   ```
   https://your-domain.com/webhook
   ```

3. Настройте навык MAX с параметрами:
   - Endpoint: `https://your-domain.com/webhook`
   - Access Token: скопируйте из MAX консоли в `.env`

### Пример запроса от MAX

```json
{
  "session": {
    "user_id": "user123"
  },
  "request": {
    "original_utterance": "начать"
  }
}
```

### Пример ответа

```json
{
  "version": "1.0",
  "response": {
    "text": "Как вас зовут?",
    "end_session": false
  }
}
```

## API Endpoints

### POST /webhook
Основной webhook для обработки сообщений от MAX
- **Body**: JSON с message от MAX API

### GET /health
Проверка статуса приложения
- **Response**: `{"status": "ok"}`

### GET /export
Экспорт всех собранных ответов
- **Headers**: `Authorization: Bearer {ADMIN_TOKEN}`
- **Response**: JSON с полным экспортом

В опроснике доступны следующие команды:

| Команда | Действие |
|---------|----------|
| `Начать` / `start` | Начать новый опрос |
| `Результаты` | Показать ваши ответы |
| `Отмена` / `cancel` | Отменить текущий опрос |

## Расширение функциональности

### Добавить новые вопросы

Отредактируйте `self.questions` в классе `SurveyBot`:

```python
{
    "id": "question_id",
    "text": "Текст вопроса?",
    "type": "text|email|phone|choice",
    "options": ["Вариант 1", "Вариант 2"],  # Для type=choice
    "required": True
}
```

### Добавить уведомления

```python
# Отправить email с новыми ответами
import smtplib
# Код отправки уведомлений...
```

### Интеграция с базой данных

Замените сохранение в JSON на запросы к БД:

```python
# Вместо self.save_responses()
db.users.insert_one(self.responses[user_id])
```
