## Что запускать

Тому, кто просто скачал папку, ничего из таблицы знать не нужно:
**«Запустить-бота»** — и всё. Ярлык сам создаёт окружение, ставит
библиотеки, спрашивает токен один раз и проверяет, всё ли на месте.
Рядом лежат «Рабочее-место», «Проверка» и «Связь-с-MAX»; на Linux
и macOS то же самое делает `./запустить.sh`.

| Команда | Что делает | Когда |
|---|---|---|
| `Запустить-бота.bat` | Окружение, библиотеки, токен, проверка и старт | Обычный запуск на Windows |
| `./запустить.sh` | То же самое на Linux и macOS | Обычный запуск |
| `python launcher.py check` | Только проверка: анкета, база, согласие, шкала | Перед сменой |
| `python max_bot.py` | Бот забирает события сам | Разработка на ноутбуке |
| `python max_webhook.py` | Бот принимает события по вебхуку | Боевая среда |
| `python crm_server.py` | CRM оператора, `localhost:5001` | Работа с обращениями |
| `python export_excel.py` | Выгрузка обращений и звонков | По требованию |
| `python crm_store.py` | Завести оператора CRM | Один раз |
| `python diagnose.py` | Проверить связь, токен и файлы | Когда бот молчит |
| `pytest` | 402 проверки | Перед каждым изменением |
| `python knowledge.py <вопрос>` | Что бот найдёт в базе по вопросу | При правке базы |
| `python scale_731.py` | Покрытие шкалы Приказа № 731 | При правке анкеты |
| `python fallback.py` | Что бот отвечает, когда не понял | При правке этих фраз |
| `python -c "import knowledge; print(knowledge.карта())"` | Карта тем: ветви и сколько в каждой | При правке карты |
| `python webapp/инструкция/сборка-видео.py` | Пересобрать видеомануал из бота | После правки вопросов |

## Как это держится вместе

Сценарий анкеты (`survey_questions.py`) — только данные: тексты, варианты,
условия ветвления. Движок (`chatbot_survey.py`) ничего не знает про MAX,
транспорт (`max_bot.py`) ничего не знает про содержание вопросов. Поэтому:

* согласие живёт в двух длинах: короткий экран и полный текст по кнопке,
  оба — из `chatbot_survey.py`. Из тех же констант собирается Приложение А
  комплекта форм, поэтому бумага не может разойтись с чатом;
* CRM и выгрузка читают ответы, но никогда не пишут в файл анкеты.
  Переписка устроена так же: входящее пишет бот в файл анкеты,
  исходящее — CRM в свой, а сводятся они только на чтение;
* видеомануал рисуется той же функцией `max_bot.layout`, которой бот
  строит настоящие кнопки, — разойтись с ботом он не может;
* поменять вопрос — значит поменять одну запись в `survey_questions.py`
  и пересобрать мануал;
* база знаний собирается из `база/*.md`, из самого справочника
  `webapp/index.html` и из `scale_731.py` — вторых копий ни справочника,
  ни позиций приказа не существует, поэтому бот, страница и выгрузка
  для эксперта не могут разойтись;
* модель — надстройка над базой, а не замена ей. Выключена по умолчанию,
  отвечает только по найденным статьям, и её отказ ничего не ломает;
* на непонятое бот отвечает не одной фразой, а лесенкой из `fallback.py`:
  счёт непониманий подряд ведёт анкета, ответ выбирает лесенка, и ниже
  последней ступени бот не опускается — молчания нет ни при каком вводе;
* по базе человек ходит не списком, а картой: одиннадцать ветвей
  (`knowledge.КАРТА`), внутри по шесть тем на страницу, у статьи —
  путь первой строкой и кнопки «в раздел», «все темы», а у того, кто
  не дозаполнил анкету, ещё и «вернуться к анкете». Тест проверяет,
  что ни один экран не тупик и ни одна статья не потерялась.

## Чего в репозитории нет и не будет

`token.txt`, `survey_responses.json`, `crm_data.json`, `operators.json`,
`.crm_secret`, `.webhook_secret`, `outbox/` (вместе с `outbox/files/` —
вложениями оператора) — токен и данные людей.
Внесены в `.gitignore`; проверено, что за всю историю ни один из них
не попадал в коммиты.

## Что держит запуск

1. **Правовое основание.** Формы готовы, нужен юрист: подтвердить
   двухступенчатую схему и утвердить тексты. Пять вопросов — в начале
   `docs/Согласие-на-обработку-ПД-СДУТ.docx`.
2. **Боевое развёртывание.** Домен, сертификат доверенного центра, порт
   из разрешённых MAX. Подробности — в `max_webhook.py`.
3. **Полнота оценочной шкалы.** Действующая анкета закрывает 12 позиций
   из 21 — максимум 32 балла, то есть II уровень. III уровень (25–28 часов
   помощи) по ней недостижим в принципе: `python scale_731.py` показывает,
   каких девяти позиций не хватает. Расширение анкеты — отдельная работа
   и отдельное решение, начинать её раньше юриста нельзя.
