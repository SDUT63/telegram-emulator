# «Точка входа» — что где лежит

Оглавление проекта АНО «СДУТ». Всё, что сделано, — здесь; искать по
переписке не нужно.

Ветка: `claude/chat-bot-survey-publik-nq2w1s`.
Бот в MAX: [SDUT63](https://max.ru/id6320093220_bot) ·
справочник: [sdut.d-lemeshev88.workers.dev](https://sdut.d-lemeshev88.workers.dev/)

## Что запускать

| Команда | Что делает | Когда |
|---|---|---|
| `python max_bot.py` | Бот забирает события сам | Разработка на ноутбуке |
| `python max_webhook.py` | Бот принимает события по вебхуку | Боевая среда |
| `python crm_server.py` | CRM оператора, `localhost:5001` | Работа с обращениями |
| `python export_excel.py` | Выгрузка обращений и звонков | По требованию |
| `python crm_store.py` | Завести оператора CRM | Один раз |
| `python diagnose.py` | Проверить связь, токен и файлы | Когда бот молчит |
| `pytest` | 69 проверок | Перед каждым изменением |

## Чего в репозитории нет и не будет

`token.txt`, `survey_responses.json`, `crm_data.json`, `operators.json`,
`.crm_secret`, `.webhook_secret`, `outbox/` — токен и данные людей.
Внесены в `.gitignore`; проверено, что за всю историю ни один из них
не попадал в коммиты.

## Что держит запуск

1. **Правовое основание.** Формы готовы, нужен юрист: подтвердить
   двухступенчатую схему и утвердить тексты. Пять вопросов — в начале
   `docs/Согласие-на-обработку-ПД-СДУТ.docx`.
2. **Боевое развёртывание.** Домен, сертификат доверенного центра, порт
   из разрешённых MAX. Подробности — в `max_webhook.py`.
