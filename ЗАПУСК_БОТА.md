# Запуск чат-бота СДУТ в MAX

Пошаговая инструкция для Windows. Версия с кнопками «копировать» и отметками
о выполненных шагах — по ссылке, которую прислал ассистент.

## Ноутбук или сервер

Бот сам подключается к серверам MAX и забирает сообщения (long polling). Ему
**не нужен** публичный адрес, домен, сертификат и открытый порт. Поэтому он
запускается прямо на ноутбуке.

- **Ноутбук** — работает, пока открыто окно с ботом. Закрыли — бот замолчал,
  ответы сохранены. С этого стоит начать.
- **Сервер** — нужен только для круглосуточной работы. 2 ГБ хватит с большим
  запасом: боту нужно около 100 МБ.

Домен и сертификат понадобятся отдельно и только для страницы-справочника
(мини-приложение MAX открывается по HTTPS). К боту это отношения не имеет.

## Шаг 1. Установить Python

1. Откройте **python.org/downloads**, нажмите **Download Python**.
2. Запустите скачанный файл.
3. **Поставьте галочку «Add python.exe to PATH»** внизу первого окна.
4. **Install Now** → дождитесь → **Close**.

> Галочка PATH — единственное место, где легко ошибиться. Без неё компьютер
> не найдёт Python.

## Шаг 2. Скачать файлы

1. Откройте **github.com/SDUT63/telegram-emulator**
2. Переключите ветку на `claude/chat-bot-survey-publik-nq2w1s`
   (кнопка выбора ветки слева над списком файлов).
3. **Code** → **Download ZIP**.
4. Распакуйте архив, перенесите папку в **Документы**, переименуйте в `sdut-bot`.

В репозитории есть и другие файлы — эмулятор Telegram. Они не мешают.

## Шаг 3. Открыть PowerShell в этой папке

1. Откройте папку `sdut-bot` в проводнике.
2. Щёлкните в **адресную строку** вверху окна.
3. Наберите `powershell` и нажмите Enter.

Проверка:

```powershell
python --version
```

Должно вывести `Python 3.13.x`. Если открылся Microsoft Store или «python не
распознано» — не встала галочка PATH; попробуйте `py --version` и дальше
используйте `py` вместо `python`.

## Шаг 4. Установить библиотеки

```powershell
python -m pip install maxapi flask
```

В конце должно быть `Successfully installed maxapi-… flask-…`.

## Шаг 5. Создать бота в MAX

1. В MAX найдите бота **@MasterBot**.
2. Отправьте `/create`.
3. Имя бота — его увидят люди, например «СДУТ — приём обращений».
4. Ник — 11–60 символов, обязательно оканчивается на `_bot`, например
   `sdut_priem_bot`. **Изменить потом нельзя.**
5. MasterBot пришлёт **токен** — скопируйте его.

> **Токен — это ключ от бота.** Кто его получит, сможет писать людям от имени
> организации. Не пересылайте в переписке, не публикуйте.

С августа 2025 публикация ботов в MAX доступна верифицированным юрлицам РФ —
АНО «СДУТ» подходит, при публикации понадобятся документы организации.

## Шаг 6. Положить токен в файл

```powershell
notepad token.txt
```

Блокнот спросит, создать ли файл — **Да**. Вставьте токен одной строкой, больше
ничего. Ctrl+S, закрыть.

Файл `token.txt` внесён в `.gitignore` — случайно выгрузить ключ не получится.

## Шаг 7. Запустить

```powershell
python max_bot.py
```

Должна появиться рамка «Бот запущен: …». **Окно не закрывайте** — пока оно
открыто, бот отвечает.

## Шаг 8. Проверить

Найдите бота в MAX по нику, напишите что угодно. Он поздоровается и задаст
первый вопрос. В окне PowerShell видно каждое входящее сообщение.

Анкета из 29 вопросов, но не подряд: сначала 7 обязательных, потом бот
предлагает ответить подробнее — тоже кнопками, «Продолжить, я отвечу» или
«Достаточно, свяжитесь со мной».

**Варианты ответа приходят кнопками.** Нажал — ответ записан, бот задаёт
следующий вопрос. Там, где можно отметить несколько, кнопки переключаются:
отмеченное помечается галочкой, внизу появляется «Готово». Печатать номера
по-прежнему можно — для тех, кому так привычнее, и на случай, если кнопки
почему-то не отобразились.

В меню бота (значок слева от поля ввода) есть команды: `/start` — начать,
`/answers` — показать заполненное, `/help` — подсказка, `/cancel` — прервать.
Меню записывается в MAX при каждом запуске `python max_bot.py`.

Те же слова понимаются и текстом в любой момент: `далее` — пропустить
необязательный вопрос, `назад` — вернуться, `ответы` — показать заполненное,
`заново` — начать сначала, `отмена` — прервать.

Анкета сохраняется: человек может закрыть чат и вернуться позже. `/start` на
недозаполненной анкете возвращает к тому же вопросу и ничего не стирает —
стирает только `заново`.

> **Бот отвечает, только пока открыто окно PowerShell.** Кнопка мини-приложения
> со справочником видна в MAX всегда — её показывает сам мессенджер, а не бот.
> Поэтому по ней нельзя понять, работает бот или нет: если он молчит на
> сообщения, первым делом проверьте, что окно с `python max_bot.py` открыто.

## Шаг 9. Забрать ответы

В **новом** окне PowerShell (не закрывая то, где работает бот):

```powershell
ii survey_responses.csv
```

Откроется Excel. Кириллица открывается корректно — файл пишется с BOM.

Рядом лежит `survey_responses.json` — тот же список для программ, бот хранит
там же, кто на каком вопросе остановился. Вручную не редактируйте.

## Если бот пишет про сертификат

```
SSLCertVerificationError: [SSL: CERTIFICATE_VERIFY_FAILED]
certificate verify failed: unable to get local issuer certificate
```

Токен тут ни при чём — до его проверки дело не дошло. Python не смог убедиться,
что на том конце действительно MAX.

У MAX несколько адресов API, и сертификаты у них выданы разными
удостоверяющими центрами. Какой именно адрес использует бот — решает
библиотека `maxapi`, поэтому чаще всего проблема лечится её обновлением,
а не вознёй с сертификатами.

Сначала запустите проверку — она скажет точно, в чём дело:

```powershell
python diagnose.py
```

**Решение 1 — обновить библиотеку. Помогает почти всегда.**

```powershell
python -m pip install --upgrade maxapi
```

У MAX несколько адресов, и сертификаты у них разные. Версия `maxapi` 1.2.0
обращалась к `platform-api.max.ru`, где сертификат выдан греческим центром
HARICA, которого в Windows обычно нет. Свежие версии используют
`platform-api2.max.ru` с сертификатом Минцифры **и везут оба российских
сертификата с собой** — поэтому после обновления всё начинает работать даже
без ручной установки сертификатов.

Проверить версию: `python -m pip show maxapi`. Нужна 1.2.2 или новее.

**Решение 2 — отключить VPN.** MAX российский, ему VPN не нужен, а через
зарубежный узел соединение может подменяться.

**Решение 3 — поставить сертификаты Минцифры.** Откройте **gosuslugi.ru/crt**,
скачайте оба файла для Windows, установите каждый двойным щелчком в хранилище
«Доверенные корневые центры сертификации». Закройте и заново откройте PowerShell.

**Решение 4 — антивирус.** Kaspersky, ESET, Dr.Web подменяют сертификаты собой.
Отключите проверку защищённых соединений для `platform-api.max.ru`.

**Решение 5 — надёжное, если ничего не помогло.** Не полагаемся на
хранилище Windows, а даём боту свой список:

1. Скачайте с **gosuslugi.ru/crt** оба файла для Windows (`.cer`).
2. Положите их прямо в папку с ботом, рядом с `max_bot.py`.
3. Выполните:

```powershell
python add_cert.py
```

Скрипт соберёт `certs.pem` из ваших файлов плюс всех сертификатов, которым
Python доверял раньше, — ничего не потеряется. Бот подхватит файл сам.

4. Запускайте бота как обычно: `python max_bot.py`

Файл `certs.pem` нужен только этому компьютеру, в репозиторий он не попадает.

> **Отключать проверку сертификатов нельзя.** Через это соединение идут токен
> бота и данные обратившихся: имена, телефоны, описания состояния близких.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `SyntaxError` и в тексте видно `<!DOCTYPE html>` | Файл скачался без VPN: вместо кода сохранилась страница «App unavailable in region». Раздел ниже |
| `Имя "python" не распознано` | Не встала галочка PATH. Переустановить Python или использовать `py` |
| Открылся Microsoft Store | То же самое. Ставьте с python.org, не из Store |
| **Не найден токен бота** | Нет файла `token.txt` рядом с `max_bot.py` |
| `CERTIFICATE_VERIFY_FAILED` | Раздел выше про сертификаты |
| **Не удалось подключиться к MAX** | В `token.txt` не токен (кавычки, пробелы, лишние строки) либо нет интернета |
| `No module named 'maxapi'` | Пропущен шаг 4 |
| `aiogram … requires aiohttp<3.11` | Не мешает. Предупреждение от другой библиотеки на компьютере; нашему боту нужен новый aiohttp |
| Бот молчит, видна только кнопка мини-приложения | Окно с `python max_bot.py` закрыто. Кнопку показывает сам MAX, она работает и без бота. Откройте окно заново |
| Бот молчит, окно открыто | Проверьте, что пишете именно своему боту: в окне видно все входящие. Если пусто — `python diagnose.py`, он проверит и связь, и токен |
| В меню бота пусто, нет команд | Меню записывается при запуске. Запустите `python max_bot.py` и подождите строку «Меню команд обновлено» |
| Кнопки под вопросом не появляются | Обновите библиотеку: `python -m pip install --upgrade maxapi`. Пока их нет, отвечать можно номерами — анкета это понимает |
| В Excel «кракозябры» | Откройте двойным щелчком из проводника, а не импортом |

## Если в файле оказалась веб-страница

```
SyntaxError: leading zeros in decimal integer literals are not permitted
```

а в первой строке видно `<!DOCTYPE html>` и слова **App unavailable in region**.

Это не ошибка кода. Файл скачался **при выключенном VPN**: Claude недоступен
в регионе, браузер получил страницу-заглушку и сохранил её под именем `.py`.

Проверить, какие файлы пострадали:

```powershell
Get-ChildItem *.py | ForEach-Object {
  $first = Get-Content $_ -TotalCount 1
  if ($first -match '<!DOCTYPE|<html') { "ПОВРЕЖДЁН  $($_.Name)" } else { "ок         $($_.Name)" }
}
```

**Как чинить.** Берите файлы с GitHub, а не из переписки — GitHub открывается
без VPN:

1. **github.com/SDUT63/telegram-emulator**
2. Ветка `claude/chat-bot-survey-publik-nq2w1s`
3. **Code** → **Download ZIP**
4. Заменить `.py` файлы, **не трогая** `token.txt` и файлы с ответами

> **Правило простое.** Скачиваете файлы из переписки — VPN включён.
> Запускаете бота — VPN выключен. MAX российский, ему VPN мешает.

## Как устроены файлы

| Файл | Что делает |
|---|---|
| `max_bot.py` | Бот для MAX. Это его вы запускаете |
| `survey_questions.py` | **Сами вопросы и варианты ответов.** Здесь правят формулировки |
| `chatbot_survey.py` | Как анкета ведёт диалог: ветвления, проверки, сохранение |
| `webapp_server.py` | Отдаёт страницу-справочник. К боту отношения не имеет |
| `webapp/` | Страница «Навигатор помощи» и постеры |
| `diagnose.py` | Проверка связи с MAX, если бот не подключается |

| `token.txt` | Ключ от бота. Создаёте вы, в репозиторий не попадает |
| `survey_responses.json` | Ответы и состояние анкет |
| `survey_responses.csv` | Те же ответы таблицей для Excel |

### Изменить вопросы анкеты

Все вопросы лежат в `survey_questions.py`, в списке `QUESTIONS`. Логику
трогать не нужно — она в другом файле. Кнопки бот делает из `options` сам:
добавили вариант — появилась кнопка, ничего больше править не надо.

Один вопрос выглядит так:

```python
{
    "id": "mobility",              # имя столбца в таблице
    "section": "Подвижность",      # заголовок раздела, показывается один раз
    "text": "Как человек передвигается?",
    "kind": "choice",              # choice | text | phone | email
    "options": [
        "Ходит сам",
        "Ходит с опорой: трость, ходунки",
        "Не встаёт с постели",
    ],
    "required": True,              # False — можно пропустить словом «далее»
    "when": continues,             # задавать ли вопрос вообще
},
```

Полезные поля:

- `"multi": True` — можно отметить несколько вариантов: кнопки переключаются
  галочкой, внизу появляется «Готово». Вариант, начинающийся со слова
  «Ничего», снимает остальные — чтобы ответ не противоречил сам себе
- `"when"` — вопрос задаётся только при определённых прошлых ответах.
  Например, про пролежни спрашивают лишь у лежачих
- `"alert"` — если выбран опасный вариант, бот сразу выдаёт предупреждение
  и помечает обращение как требующее внимания

Проверить изменения, не трогая бота и живые ответы:

```powershell
python chatbot_survey.py
```

Анкета прогонится сама с собой и покажет весь диалог. Демонстрация пишет в
отдельные файлы, реальные обращения не затрагиваются.

## Перенос на сервер

Когда бот поработает на ноутбуке. Порядок тот же, команды линуксовые: Python,
те же файлы, `token.txt`, запуск как службы, чтобы поднимался после
перезагрузки.

> **Нельзя держать один токен запущенным в двух местах одновременно.** Прежде
> чем запускать на сервере, остановите бота на ноутбуке — иначе они начнут
> перехватывать сообщения друг у друга.
