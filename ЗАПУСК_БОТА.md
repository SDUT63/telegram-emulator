# Запуск чат-бота СДУТ в MAX на ноутбуке

Это инструкция именно для бота MAX. Файлы с названием `telegram-emulator` в репозитории нужны только как часть проекта и не являются транспортом бота.

## Самый простой запуск Windows

1. Скачайте ZIP именно ветки `max-bot-complete-2026`.
2. Распакуйте папку.
3. Установите Python 3.10+ (рекомендуется 3.13).
4. Откройте PowerShell в папке.
5. Выполните:

```powershell
python launcher.py
```

Launcher создаст `.venv`, установит зависимости, попросит токен MAX при первом запуске и запустит `run_max.py`.

## Токен

В MAX откройте `@MasterBot`, выполните `/create` и получите токен. Если launcher спросит его — вставьте одной строкой. Токен сохранится в `token.txt`. Файл не коммитится в Git.

Можно создать файл вручную:

```powershell
notepad token.txt
```

## Что запускается

`launcher.py` → `run_max.py` → проверенный `max_bot.py`.

`run_max.py` подключает:

- SQLite-хранилище `data/sdut_bot.sqlite3`;
- сохранение состояния анкеты между перезапусками;
- persistent-защиту от повторной доставки событий.

Основной `max_bot.py` не переписывается и остаётся эталонным рабочим транспортом.

## Важное ограничение

Для тестирования на ноутбуке используется **long polling**. Публичный IP, домен, HTTPS и открытый порт для этого режима не нужны. Окно с ботом должно оставаться открытым.

Вебхук `max_webhook.py` предназначен для отдельного серверного режима и для ноутбучного теста не нужен.

## Проверка

Запуск:

```powershell
python launcher.py
```

После сообщения `Бот запущен` найдите бота в MAX и напишите ему любое сообщение.

Остановить: `Ctrl+C`.

При следующем запуске состояние анкеты и база SQLite сохраняются.

## Диагностика

Если MAX не подключается:

```powershell
python diagnose.py
```

Если библиотека устарела:

```powershell
python -m pip install --upgrade maxapi
```

## Данные

Рабочая база находится в `data/sdut_bot.sqlite3` и исключена из Git. Не передавайте её третьим лицам: в ней может находиться персональная информация обращавшихся.
