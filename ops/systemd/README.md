# Круглосуточная работа: systemd

Бот, запущенный из окна терминала, живёт до первой перезагрузки сервера
и до первого падения. Для службы, которую показали в рекламе, это
значит: люди пишут, а им никто не отвечает, и узнают об этом наутро.

Здесь юниты, которые поднимают бота при старте машины и после сбоя,
и таймеры для того, что должно происходить само: резервные копии
и удаление данных по истечении срока хранения.

## Установка

```bash
sudo install -d -o sdut -g sdut /opt/sdut
# развернуть код в /opt/sdut, создать /opt/sdut/.venv

sudo cp ops/systemd/*.service ops/systemd/*.timer /etc/systemd/system/
sudo systemctl daemon-reload
```

## Настройки и пароли

Юниты читают `/etc/sdut/bot.env` — файл с переменными окружения. Он
содержит адрес базы с паролем, поэтому:

```bash
sudo install -d -m 750 -o root -g sdut /etc/sdut
sudo install -m 640 -o root -g sdut /dev/null /etc/sdut/bot.env
```

Что в нём должно быть, перечисляет `python preflight.py`. Как минимум:

```
SDUT_DATABASE_URL=postgresql://sdut:ПАРОЛЬ@127.0.0.1:5432/sdut
MAX_BOT_TOKEN=...
SDUT_BACKUP_PASSPHRASE_FILE=/etc/sdut/backup.key
SDUT_CASE_RETENTION_DAYS=...   # срок назначает служба
```

## Запуск

```bash
sudo systemctl enable --now sdut-bot.service sdut-crm.service
sudo systemctl enable --now sdut-backup.timer sdut-retention.timer
```

## Проверить, что работает

```bash
systemctl status sdut-bot
journalctl -u sdut-bot -f          # логи бота, JSON-строками
systemctl list-timers 'sdut-*'     # когда следующая копия и чистка
```

## Почему так

**`Restart=always` с задержкой.** Упавший бот поднимается сам. Задержка
в пять секунд нужна, чтобы при недоступной базе он не крутился в цикле
перезапусков, забивая журнал.

**Бот и CRM — разные службы.** CRM слушает только этот компьютер
и с людьми не разговаривает; падение одного не должно уносить другое.

**`ExecStartPre` с preflight.** Бот не поднимется с недоделанной
настройкой: без миграций, без ключа резервных копий, с паролем
оператора по умолчанию. Лучше не подняться и сказать об этом в журнале,
чем принимать людей и терять их карточки.

**Ограничения прав.** Служба не имеет доступа к домашним каталогам,
не может повысить права и пишет только туда, куда ей положено.
За этой границей персональные данные, и сужать её дёшево.

**Таймеры вместо cron.** `Persistent=true` означает: если машина была
выключена в час резервной копии, копия снимется сразу после включения,
а не пропустится молча до завтра.
